
# Project Timeline

## Objective
Define a structured plan for Verilog to TL-Verilog conversion using AI.

---

## Phase 1: Understanding & Setup (Week 1)
- Study Verilog and TL-Verilog basics
- Understand pipeline-based design concepts
- Set up project structure

---

## Phase 2: Dataset Preparation (Week 2)
- Collect Verilog modules (counter, ALU, FSM)
- Organize dataset:
  - raw_verilog
  - tlv_outputs
  - paired_data

---

## Phase 3: Prompt Engineering (Week 3)
- Design reusable prompt templates:
  - Basic conversion
  - Pipeline conversion
  - FSM conversion
- Test prompts with sample inputs

---

## Phase 4: AI Integration (Week 4)
- Build script for prompt injection
- Generate TL-Verilog outputs
- Store results

---

## Phase 5: Evaluation (Week 5)
- Define evaluation metrics
- Compare outputs (manual vs AI)
- Perform error analysis

---

## Phase 6: Optimization (Week 6)
- Improve prompts
- Fix common errors
- Enhance pipeline handling

---

## Final Phase: Documentation & Submission
- Prepare reports
- Write documentation
- Final testing and cleanup
