
# Full Pipeline

## Overview

This system converts Verilog designs into TL-Verilog using AI-driven prompts.

## Pipeline Flow

Verilog Input
    ↓
Input Processing
    ↓
Prompt Injection
    ↓
AI Conversion
    ↓
TL-Verilog Output
    ↓
Post Processing
    ↓
Final Output

## Components

1. Dataset
   - Raw Verilog files

2. Prompt Engine
   - Template-based prompts

3. AI Model
   - Performs conversion

4. Output Storage
   - Stores TL-Verilog files

## Key Features

- Reusable prompt templates
- Pipeline-aware conversion
- FSM handling support
- Scalable architecture
