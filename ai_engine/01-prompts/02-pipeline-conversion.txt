Requirements:

- Ensure correct signal propagation across stages

Instructions:
- Convert clocked always blocks into pipeline stages
- Use >> operator for stage transitions
- Maintain data flow consistency

Focus:
- Pipeline clarity
- Correct timing abstraction

Output:
- Only TL-Verilog code

Verilog Code:
module verilog_counter(
    input clk,
    input reset,
    output reg [3:0] count
);

always @(posedge clk) begin
    if (reset) begin
        count <= 4'b0000;
    end
    else begin
        count <= count + 1;
    end
end

endmodule
